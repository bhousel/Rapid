- **DashLine halo fixes** (May 2026) — `PixiLayerMapUI.reset()` iterates a children snapshot to avoid splice-during-iteration. `AbstractPixiFeature.destroy()` uses `halo.destroy({ children: true })`. Line/Polygon halos get `scale: localScale` in `HALO_STYLE` so DashLine converts world-unit widths correctly. Root cause for dashes appearing wrong: (1) `DashLine.strokeStyle.textureSpace` was effectively `'local'` for a while — that branch stretches the texture across each segment's bounding box, making longer segments show longer dashes. Reverted to `'global'`. (2) The pattern texture canvas is pow2-padded for WebGL1 REPEAT-wrap support, but under `'global'` with a uniform matrix scale that made the cycle length wrong by `nextPow2(dashSize)/dashSize`. Fixed by storing the texture's pow2 dimensions on the DashLine instance and non-uniformly scaling the per-segment matrix by `(dashSize / texW, width / texH)`. Also reordered matrix composition to scale-then-rotate (non-uniform scale requires this to keep the texture-x axis aligned with the line direction).
